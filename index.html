Zig-first tooling

Smart editing

Syntax highlighting, bracket auto-close, 120+ IntelliSense completions, 29 Zig snippets (fn, struct, gpa, al...). Ctrl+D multi-select, inline error ghost text.

Run & build instantly

F5 → zig run, F7 → zig build, F8 → zig test. Interactive stdin & live output. Stop process with Ctrl+C. Build steps panel reads build.zig.

Human-readable errors

Problems panel with plain‑English explanations and fix suggestions. Error squiggles, click-to-jump, auto-check after 2.5s idle.

Project templates

5 starters: Executable (CLI), Library, TCP Server, Embedded (Cortex-M4), Comptime Metaprogramming. Auto‑creates files and opens main.zig.

Integrated terminal + Git

Full ANSI terminal, command history, branch name, Git status (M/A/?) in file tree. Zig detection with registry & PATH scanning.

Native & responsive

Built with Go + Wails, WebView2 (Windows). Font size shortcuts, word wrap toggle, multi‑tab, save before close, and ultra‑low memory.
